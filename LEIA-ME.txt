MEU CARRO - como colocar no ar (gratis, GitHub Pages)

1. Crie um repositorio PUBLICO no GitHub (ex.: meu-carro).
2. Envie TODOS os arquivos desta pasta para a raiz do repositorio
   (index.html, manifest.json, sw.js, kuromi.png, favicon.png, favicon.ico, icon-*.png).
3. Settings > Pages > Branch: main / pasta: (root) > Save.
4. Em 1-2 minutos o site abre em https://SEU-USUARIO.github.io/meu-carro/

No iPhone (Safari): abrir o link > Compartilhar > Adicionar a Tela de Inicio.
Use sempre pelo icone da tela inicial. Anote so depois de instalar.
Faca "Salvar backup dos dados" de vez em quando (tela inicial do app).

Ao alterar o codigo, aumente o numero em CACHE = 'meu-carro-vX' no sw.js.
